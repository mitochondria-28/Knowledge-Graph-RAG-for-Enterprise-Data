# Orion Platform

Orion Platform is TechNova's next-generation data orchestration layer, announced in Q3 2025.
It unifies real-time streaming, batch processing, and ML inference into a single runtime.

## Key Features

- Sub-millisecond latency for event processing pipelines
- Native integration with StellarDB and the Apex ML Platform
- Built-in lineage tracking for all data transformations
- Supports 40+ connectors including Kafka, Snowflake, and Databricks

## Team

The Orion Platform is led by Director of Engineering Priya Nair, with a core team of 12 engineers
drawn from the former DataBridge ETL group after the Apex Analytics acquisition.

## Status

Currently in private beta with three enterprise customers. General availability is targeted for Q1 2026.
